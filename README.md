# 數學電子白板

國小數學課用的觸控白板網頁，像簡報一樣分頁，可以放圖片、打字、畫圓和扇形（畫的時候會即時顯示圓心角度數），並且可以在上面手寫。登入 Google 帳號後，黑板會同步到你的 Google 雲端硬碟，在家備課、到學校換電腦都能接著用。

整套設定分四個部分，第一次大約需要 30 分鐘，之後就不用再碰：

1. 把網頁放上 GitHub Pages，取得固定網址
2. 在 Google Cloud 申請「OAuth 用戶端 ID」（讓網頁可以存取你的雲端硬碟）
3. 把用戶端 ID 填進 `config.js`
4. 第一次登入

你需要準備：一個 GitHub 帳號、一個 Google 帳號。Google 帳號建議用**個人 Gmail**，學校發的教育版帳號常會封鎖這類自建應用程式。

下文所有 `你的帳號` 都請換成你自己的 GitHub 帳號名稱。

---

## 第一部分：放上 GitHub Pages

### 1-1 建立 repository（儲存庫）

repository（簡稱 repo）就是 GitHub 上放一個專案檔案的資料夾。

1. 登入 [github.com](https://github.com)，按右上角的 **＋** → **New repository**。
2. **Repository name** 填 `math-whiteboard`（可以自己取，但只能用英文、數字和連字號，而且會出現在網址裡）。
3. 選 **Public**。免費帳號要公開的 repo 才能用 GitHub Pages。公開的只有程式碼，你的黑板內容存在你的雲端硬碟，不會公開。
4. 按 **Create repository**。

### 1-2 上傳檔案

1. 在剛建好的 repo 頁面，點 **uploading an existing file**（或 **Add file → Upload files**）。
2. 把這三個檔案拖進去：`index.html`、`config.js`、`README.md`。
3. 拉到下面按 **Commit changes**。

### 1-3 開啟 GitHub Pages

1. 在 repo 頁面上方點 **Settings**，左側選單點 **Pages**。
2. **Source** 選 **Deploy from a branch**。
3. **Branch** 選 `main`，資料夾選 `/ (root)`，按 **Save**。
4. 等 1 到 2 分鐘，重新整理這一頁，上方會出現網址：
   `https://你的帳號.github.io/math-whiteboard/`

打開這個網址，應該會看到白板首頁，上面寫著「雲端同步還沒設定」。到這一步，白板已經可以用，只是資料還只存在那台電腦。

---

## 第二部分：申請 Google OAuth 用戶端 ID

Google 的設定畫面偶爾會改版，按鈕位置或名稱可能和下面略有不同，照著意思找就可以。

### 2-1 建立專案

1. 打開 [console.cloud.google.com](https://console.cloud.google.com)，用你的 Gmail 登入。第一次使用要同意服務條款。
2. 點畫面左上角的專案選單（可能寫著「選取專案」），按 **新增專案**。
3. 專案名稱填 `math-whiteboard`，按 **建立**。
4. 建好後，確認左上角顯示的是這個專案。

### 2-2 啟用 Google Drive API

1. 左側選單 →「**API 和服務**」→「**程式庫**」。
2. 搜尋 `Google Drive API`，點進去，按 **啟用**。

### 2-3 設定 OAuth 同意畫面

1. 左側選單 →「API 和服務」→「**OAuth 同意畫面**」。新版會帶你到「Google Auth Platform」，按 **開始**。
2. **應用程式資訊**：應用程式名稱填 `數學電子白板`，使用者支援電子郵件選你的 Gmail。
3. **目標對象**：選 **外部**。
4. **聯絡資訊**：填你的 Gmail。
5. 勾選同意政策，按 **建立**。

### 2-4 把自己加成測試使用者

這個應用程式只給你自己用，不需要送 Google 審核，維持「測試中」的狀態就好。但測試中的應用程式只有名單上的帳號能登入，所以要把自己加進去。

1. 在 Google Auth Platform 左側點「**目標對象**」。
2. 發布狀態維持 **測試中**，不要按「發布應用程式」。
3. 在「測試使用者」按 **新增使用者**，填你的 Gmail，按 **儲存**。

和你一起實習的同學如果也要用，可以把他的 Gmail 一起加進來，最多 100 人。

### 2-5 設定權限範圍（可略過，但建議設定）

1. 左側點「**資料存取**」→ **新增或移除範圍**。
2. 在清單裡找到 `.../auth/drive.file`（說明大致是「查看、編輯、建立及刪除您透過這個應用程式使用的 Google 雲端硬碟檔案」），打勾，按 **更新**，再按 **儲存**。

這個權限只能碰「這個白板自己建立的檔案」，看不到你雲端硬碟裡的其他東西。

### 2-6 建立用戶端 ID

1. 左側點「**用戶端**」→ **建立用戶端**。
2. **應用程式類型**選「**網頁應用程式**」，名稱隨意，例如 `白板`。
3. 在「**已授權的 JavaScript 來源**」按 **新增 URI**，填：
   ```
   https://你的帳號.github.io
   ```
   只填到 `.io` 為止，**不要**加 `/math-whiteboard`，結尾也不要加斜線。
4. 「已授權的重新導向 URI」留空。
5. 按 **建立**。
6. 畫面會顯示「用戶端 ID」，長得像 `123456789012-abcdefg.apps.googleusercontent.com`，把它複製下來。

同一個畫面還會出現「用戶端密鑰」，這個白板用不到，**不要**貼到任何地方。用戶端 ID 本身公開沒關係。

Google 說明設定生效可能要等幾分鐘，偶爾會到幾個小時。下一步登入失敗的話，先等一下再試。

---

## 第三部分：把用戶端 ID 填進 config.js

1. 回到 GitHub 的 repo 頁面，點 `config.js`，按右上角的鉛筆圖示（Edit）。
2. 把引號裡換成你的用戶端 ID：
   ```js
   window.MATHBOARD_CONFIG = {
     googleClientId: '123456789012-abcdefg.apps.googleusercontent.com'
   };
   ```
3. 按 **Commit changes**。
4. 等 1 分鐘，回到白板網址，按 `Ctrl` + `F5` 強制重新整理。首頁會出現「用 Google 帳號登入，同步到雲端硬碟」的按鈕。

---

## 第四部分：第一次登入

1. 按「用 Google 帳號登入，同步到雲端硬碟」，會跳出 Google 的登入視窗。沒跳出來的話，看網址列右邊有沒有「已封鎖彈出式視窗」的圖示，點它選擇允許。
2. 選你的 Gmail。
3. 會出現「**Google 尚未驗證這個應用程式**」。這是因為應用程式沒送審，自己用沒有問題：點 **繼續**（有些版本要先點「進階」，再點「前往 數學電子白板（不安全）」）。
4. 權限畫面上，**一定要勾選**雲端硬碟那一項，再按 **繼續**。沒勾的話可以登入，但會一直同步失敗。
5. 回到白板，上方顯示你的 Gmail 和綠點「已同步」，就完成了。

之後你的雲端硬碟裡會多一個「**數學電子白板**」資料夾，每塊黑板是裡面的一個檔案。

---

## 平常怎麼用

**在家備課**：打開網址 → 登入 → 建立或編輯黑板。內容會自動存檔，並在幾秒內同步到雲端。首頁卡片出現黃色的「未同步」標籤，代表還沒上傳完成。

**到學校上課**：

1. 在教室電腦開一個**無痕視窗**（Chrome、Edge 都是按 `Ctrl` + `Shift` + `N`），打開白板網址。
2. 登入 Google，首頁會出現標著「在雲端」的黑板卡片。
3. 點開黑板就會下載，下載完照常上課，課堂上寫的東西也會同步回去。
4. 下課在首頁按「登出」→「**登出並清除這台電腦的黑板**」，再關掉無痕視窗。

用無痕視窗的原因是：關掉視窗後，Google 登入狀態和瀏覽器暫存都會一起清掉，下一位使用這台電腦的人看不到你的帳號。如果學校電腦的無痕視窗不能用，就用一般視窗，但下課除了在白板按「登出並清除」，還要到 Google 網站登出你的帳號。

**上課中連線逾時**：Google 給的登入許可大約一小時會過期。過期後，工具列左邊、黑板名稱旁的雲端按鈕會變成「按我連線」，這時你寫的內容還是會存在那台電腦，不會遺失，也不影響上課。下課前按一下那個按鈕重新連線，內容就會同步上去。

**兩台電腦都改過同一塊黑板**：如果某台電腦在離線時改過黑板，另一台也改了，打開時會問你要用哪一份。沒選的那一份會被覆蓋，所以盡量不要同時在兩台電腦改同一塊黑板。

**刪除**：在首頁刪除黑板，雲端硬碟的檔案會移到垃圾桶，30 天內可以從雲端硬碟救回。

**沒有網路時**：已經下載過的黑板照樣打得開、寫得了，連上網路後再同步。從來沒在這台電腦打開過的黑板，就需要網路才能下載。

**備份**：首頁每張卡片都有「匯出檔案」，會存成一個 `.json` 檔，可以用「匯入檔案」還原。重要的課前一晚建議匯出一份放隨身碟，以防學校網路出問題。

## 疑難排解

| 狀況 | 原因與處理 |
|---|---|
| 登入視窗顯示 `origin_mismatch` 或 `redirect_uri_mismatch` | 2-6 的「已授權的 JavaScript 來源」填錯。要完全等於 `https://你的帳號.github.io`，不能有路徑或結尾斜線。改完等幾分鐘再試。 |
| 顯示 `access_denied`、「尚未完成 Google 驗證程序」 | 你登入的帳號不在 2-4 的測試使用者名單裡。 |
| 登入成功，但一直顯示「同步失敗：http 403」 | 可能是 2-2 沒有啟用 Google Drive API，或第四部分沒有勾選雲端硬碟權限。啟用 API 後，在白板按「登出」→「只登出」，再重新登入並勾選權限。 |
| 按登入沒有反應 | 瀏覽器擋了彈出式視窗，請允許這個網站開啟彈出式視窗。 |
| 首頁一直寫「雲端同步還沒設定」 | `config.js` 沒填好，或瀏覽器還在用舊檔，按 `Ctrl` + `F5` 再試。 |
| 首頁寫「用檔案直接開啟時不能雲端同步」 | 你是直接雙擊打開 `index.html`。雲端同步只能用 GitHub Pages 的網址。 |

## 檔案說明

- `index.html`：白板本身，所有功能都在這個檔案裡。
- `config.js`：設定檔，只放 Google 用戶端 ID。
- 不連網路、直接雙擊 `index.html` 也能用，只是不能雲端同步，資料只存在那台電腦的瀏覽器。
